# dotfiles
My dot files.

## Install

### macOS

Install prerequisites:
```
brew install --cask alacritty
brew install gh
```

Install dotfiles:
```
cd ~
git clone https://github.com/drrcknlsn/dotfiles.git .dotfiles
~/.dotfiles/bin/install
```

## Setup

Authenticate using Github CLI:
```
gh auth login
```
